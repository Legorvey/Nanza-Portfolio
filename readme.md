## Key Features

- **UI/UX:** Premium design with glassmorphism effects, rich color palette, and micro-interactions.
- **Tech Stack:** Built with React and Vite for blazing-fast performance.
- **Dark Mode:** Fully functional Light/Dark theme toggle with local storage persistence.
- **Interactivity:** Dynamic project filtering and animated typewriter hero section.
- **Animations:** Scroll-revealed sections powered by AOS (Animate On Scroll).
- **Component Design:** Modular component-based architecture for maintainability.

## Tech Stack

### Core
- **Framework:** React
- **Build Tool:** Vite
- **Language:** JavaScript
- **Styling:** Vanilla CSS (CSS Variables for Theming)

### UI & Aesthetics
- **Animations:** AOS (Animate On Scroll)
- **Icons:** FontAwesome (via CDN)
- **Typography:** Google Fonts (Outfit, Plus Jakarta Sans)

## Getting Started

To run the project locally, follow these steps:

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd Nanza-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result. The application will hot-reload as you make changes.

## Design Philosophy

The web platform features:
- A rich `--primary-brown` (#794A34) base theme with warm cream accents.
- CSS-driven glassmorphism for depth on the navigation and content cards.
- Scroll-revealed sections from Hero to Contact, highlighting key projects and skills.
- A seamless Dark Mode that elegantly inverts colors while maintaining visual hierarchy.
